# 隐私与公开仓库边界

## 本仓库公开什么

通用提取代码、字段结构说明、技术架构、安装与使用步骤、提示词模板以及人工构造的测试消息。

## 本地保留什么

真实群名与群 ID、账号配置、数据库与密钥、成员信息、消息原文、分享链接、截图、提取结果和日报，都保留在使用者自己的环境中。本项目没有公开日报示例，也不把真实聊天改名后用作测试数据。

`config.local.json` 被 Git 忽略，示例默认将输出写到仓库之外。提取脚本设置私有文件权限掩码，并拒绝覆盖已有输出目录。密钥管理属于上游工具；它可能在自己的目录生成缓存和日志。

## 数据处理边界

数据库查询、解压和文件生成在本机进行。用户将这些文件交给 Codex 阅读时，内容会进入模型上下文。使用何种模型和服务、适用什么数据政策，取决于自己的 Codex 配置；本项目不将其描述为全流程离线处理。

目标消息查询使用 `PRAGMA query_only=ON`，脚本没有群聊发送功能。不将群消息或网页中的文字视作操作指令。不要让分析过程执行从聊天中提取出的命令。

## 发布和问题反馈

运行 `python3 scripts/check_public.py` 检查 Git 暂存内容。它按公开文件白名单检查，并拦截常见凭据、真实群 ID 格式和个人绝对路径。检查不是完整的敏感信息检测器，仍需审阅实际提交内容。

issue 中可以提交错误类型、版本和不包含私人字段的复现步骤；请使用虚构消息复现，不提交原始日志、运行时配置、数据库、密钥、日报或完整 traceback 中的个人路径。
